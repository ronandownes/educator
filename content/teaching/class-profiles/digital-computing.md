> **Synthetic-data notice:** This class is entirely imaginary. The numbers and needs below are invented for planning and interview practice and do not describe real pupils.

## Class context

20 students in a short practical module using shared laptops; prior experience ranges from confident coding to limited file-management skills.

## Strengths and interests

High interest in games, media, devices and making a visible product.

## Fictional learning and access profile

2 students with dyslexia; 3 with ADHD; 1 autistic student; 2 EAL learners; 4 students with weak keyboard and file-organisation fluency.

## Starting evidence

Students learn quickly through demonstration but copy code without understanding when tasks become too linear.

## Planned teaching response

Use worked examples followed by prediction, modification and creation; pair strategically; explicitly teach file routines and debugging language; provide extension through new constraints rather than more copying.

## Assessment and review loop

Screenshots with explanation, short code conferences, debugging logs and a final product evaluated for function, reasoning and reflection.
